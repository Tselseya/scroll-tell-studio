# Copyright and Media-Rights Checklist

The platform should treat every uploaded image, video, audio track, font, logo, screenshot, character, and likeness as rights-sensitive. A user should be able to record the source, license, restrictions, attribution, territory, expiry, and permission evidence for each asset.

Before a publish job can be confirmed, show a rights attestation:

> I own or have permission to use this media, music, text, trademark, and likeness for the selected destination, audience, territory, and duration. I have checked any platform-specific commercial, disclosure, and music-library restrictions.

The service should preserve the original asset, a checksum, uploader, rights metadata, and the consent or attestation event. It should offer a takedown intake address and a repeat-infringer process. It should not claim that AI-generated output is automatically copyright-free. The user must review provider terms, training-data restrictions, likeness issues, trademarks, and jurisdiction-specific copyright rules.

Use only stock, public-domain, Creative Commons, platform-licensed, or user-owned media whose exact license permits the intended use. A visible image URL is not proof of permission. Do not ship a default asset whose license cannot be documented.
